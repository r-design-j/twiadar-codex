# AI/Codex/GPT 个人知识沉淀 - 2026-09

## 2026-09-01

### 知识卡片: Alpha Lane Upgrade Gate

把 alpha、beta、nightly、preview 版本放进独立验证 lane，禁止自动替换生产默认。预发布版本可以用来观察方向和做灰度测试，但不能替代稳定版验收。

用户操作链路:

1. 记录版本、发布时间、来源链接、是否 prerelease 和 release body 完整度。
2. 固定验证任务，不用生产仓库首跑。
3. 标注 owner、可写目录、网络边界、凭证边界和回滚命令。
4. 跑最小真实任务并保存本地证据。
5. 只有稳定版或明确批准后才推广默认值。

风险: alpha 更新速度快，昨天可用的行为今天可能已变化。

### 知识卡片: Proxy Credential Boundary

当 agent CLI 支持企业代理、mTLS 或客户端证书时，把网络路由和凭证授权当成独立风险面，而不是普通联网能力。

用户操作链路:

1. 标明代理地址、证书来源、适用域和有效期。
2. 日志默认脱敏，不把证书路径、指纹或账号细节写入公开报告。
3. 区分模型请求、网页请求、包管理请求和 Git 请求。
4. 每次失败记录 HTTP 状态和证书错误类型，不直接重试到更宽权限。
5. 保留撤销、轮换和本地只读检查路径。

风险: 代理打通后，agent 的外联面会比原计划更宽。

### 知识卡片: Sandbox Grant Receipt

每次给 agent 授权路径、工具或开发环境，都留一张“授权小票”，写清来源、范围、原因和撤销条件。

用户操作链路:

1. 记录 grant source、path/tool、read/write、reason、owner、time。
2. 把自动检测到的 developer tools 与手动授予的权限分开。
3. 输出进入公开站点前做 local-path/secret scan。
4. 恢复会话后重新读权限，不沿用旧分类。
5. 任务完成后撤销临时授权或记录保留理由。

风险: 只看最终能访问什么，会漏掉权限是如何来的。

### 知识卡片: Replay-Safe Guardrail Contract

被 guardrail 拦截的工具输出不能再通过 replay、checkpoint、session store 或应用自有副本回到模型上下文。

用户操作链路:

1. 标注哪些输出可持久化、哪些只能本地短期审计。
2. guardrail trip 后替换或 withheld 模型可见内容。
3. 外部副作用单独记录，不因 replay 清理而假装已撤销。
4. 对 live RunState、serialized checkpoint 和 new run 三种路径分别测试。
5. 应用自有日志也做同等脱敏策略。

风险: SDK 清理 replay state 不会自动清理外部系统和应用自有存储。

## 2026-09-02

### 知识卡片: Connected-Host Queue Receipt

把手机、Remote、桌面和云端之间的排队提示当作可审计任务信封。

用户操作链路:

1. 记录 origin device、connected host、queued prompt、editable window、background-send status 和 thread ID。
2. 手机只能派工、补充和低风险审批；最终文件、测试、commit、push、deploy 仍由 Mac/Codex 收口。
3. 队列发送后必须回读任务状态，不能把“已发送”当作“已完成”。

风险: 队列同步越顺手，越容易把控制面误当执行面。

### 知识卡片: Approval Authority Split

把“AI 认为可以通过”和“AI 的批准计入合并规则”拆成两层。

用户操作链路:

1. 默认只允许 AI 给 assessment 和 comments。
2. 只有 enterprise/org/repo policy 明确开启且路径白名单命中时，approval 才能计入 required approvals。
3. 新 commit 推送后重新请求审查，旧批准自动失效。

风险: 没有拆层时，团队会误把建议性结论当成正式审批。

### 知识卡片: Expiring Budget Lane

给临时 agent 试验设置会自动到期的预算，而不是永久额度。

用户操作链路:

1. 为每个试验记录 owner、plan、budget、expires_at、允许模型和允许工具。
2. 预算到期前复核是否保留、扩容或关闭。
3. 高成本模型和长任务必须和到期预算绑定。

风险: 无到期预算会让一次试验变成长期开销。

### 知识卡片: Model Retention Policy Gate

选长任务模型前先确认数据保留、零保留资格和管理员策略。

用户操作链路:

1. 记录模型、供应商、适用入口、是否默认保留数据、ZDR/例外资格和计费模式。
2. 需要保留数据的模型默认不上私有代码和敏感知识库。
3. 管理员启用策略本身也要作为显式确认记录。

风险: 高能力模型不等于同一隐私边界。

### 知识卡片: MCP Output Ceiling Contract

给每个 MCP 工具配置输出上限和恢复后一致截断规则。

用户操作链路:

1. 记录 server name、tool name、output_token_limit、截断提示和恢复后行为。
2. 长输出工具先做摘要或分页，再进入模型上下文。
3. 公开输出前扫描凭证、本地路径和非公开状态。

风险: 工具输出过大时，截断不一致会破坏恢复、审批和复盘。

## 2026-09-03

### 知识卡片: Context Exclusion Contract

在 agent 装载上下文前就定义哪些文件、路径、资料类型不能被读取或用于推理。

用户操作链路:

1. 记录 enterprise、organization、repository 三层 exclusion 来源。
2. 把 excluded paths、适用工具、适用 agent、例外审批人写成合同。
3. 运行前读回配置，运行后做公开边界扫描。

风险: 只靠 prompt 声明“不要看”不等于运行时真的不会装载。

### 知识卡片: Managed Model Default Receipt

把默认模型当作可审计配置发布，而不是个人偏好。

用户操作链路:

1. 记录 model key、适用团队、team-mappings、是否允许用户覆盖和生效入口。
2. 默认模型变更前确认隐私、保留策略、成本、工具兼容和回滚路径。
3. 变更后抽样读回新会话默认值。

风险: 默认模型一旦错配，会把错误成本扩散到所有新任务。

### 知识卡片: Healthcare Public-Data Boundary

公共医疗资料查询和个人健康数据处理必须分成两条通道。

用户操作链路:

1. 标注问题是否只涉及公开资料。
2. PHI、病历、claims、账号内健康数据默认不进入公共数据插件。
3. 需要组织健康数据时，单独确认连接器、权限、审计和输出边界。

风险: 公共医学资料能回答问题，不代表它适合处理个人健康记录。

### 知识卡片: Mobile Attachment Queue Envelope

手机派工时把附件、队列状态、thread ID 和最终验收字段打包成任务信封。

用户操作链路:

1. 记录 origin device、queued prompt、attachment list、background-send status 和 thread ID。
2. 附件按公开、私有、需脱敏、禁止公开四类标记。
3. Mac/Codex 收口时补测试、diff、commit、push、deploy 证据。

风险: 附件越容易随手发，越需要前置公开边界。

### 知识卡片: Proxy-Egress Sandbox Gate

把 sandbox 的网络出站限制到指定代理，并把代理凭证和域名范围当作独立 gate。

用户操作链路:

1. 记录 proxy、证书/凭证来源、允许域名、工具范围和失败处理。
2. sandbox 里禁止绕过代理直接联网。
3. 失败时先记录错误类型，不自动扩大网络权限。

风险: “能联网”如果不分代理和域名，会把受控 agent 变成宽外联进程。

## 2026-09-04

### 知识卡片: Astra Model Admission Checklist

把新旗舰模型接入当成一次受控变更，而不是简单切换默认模型。

用户操作链路:

1. 记录 model key、入口、默认状态、是否在 picker 可见、上下文上限、价格和可用计划。
2. 固定允许工具、允许数据、禁止动作、预算和 fallback 模型。
3. 用一组固定任务做可重复验收，再决定是否进入默认 lane。

风险: “能配置”不等于“已经默认启用”，更不等于“适合生产任务”。

### 知识卡片: Computer-Use Permission Envelope

给能操作浏览器、桌面或 CLI 的模型套一层动作边界信封。

用户操作链路:

1. 写清允许读写的系统、路径、账号、仓库和外部服务。
2. 明确禁止交易、删数据、改安全阀、读凭证、扩大连接器或绕过审批。
3. 每个关键动作后做状态读回，异常时停止而不是补权限硬闯。

风险: 高能力 agent 更容易把“完成目标”理解成“绕过阻碍”。

### 知识卡片: Localhost Sandbox Test Gate

把 sandbox 是否允许访问本机服务当成测试前置条件。

用户操作链路:

1. 记录测试是否需要 localhost、端口和启动进程。
2. 若 sandbox 默认阻断本机服务，先判断是边界失败还是应用失败。
3. 只有必要时开启 local network，并记录原因与撤销条件。

风险: 网络边界变化会伪装成测试回归。

### 知识卡片: Reusable Workflow Provenance Receipt

对 reusable workflow 记录实际执行来源，而不是只看调用方 workflow。

用户操作链路:

1. 保存 `job.workflow_ref`、`job.workflow_sha`、`job.workflow_repository`、`job.workflow_file_path`。
2. 对第三方或跨仓库 reusable workflow 要求 sha pinning 或明确例外。
3. 把 provenance 写入 CI artifact 或发布小票。

风险: 没有来源小票时，审计只知道谁触发，不知道真正跑了哪份 workflow。

### 知识卡片: Staged Publishing OIDC Matrix

为同一个 npm 包配置多个 OIDC 发布入口，但默认只允许 staging，人审后再发布。

用户操作链路:

1. 给每个配置记录 repository、workflow、environment、是否允许 direct publish。
2. 默认 staged publishing；malware scan 完成前不开放批准。
3. 检查配置是否重叠，因为匹配是 additive 且顺序不保证。

风险: 多配置能减少长期 token，但配置重叠会扩大可发布面。
