# AI/Codex/GPT 个人知识沉淀 - 2026-09

## 2026-09-01

### 知识卡片: Alpha Lane Upgrade Gate

把 alpha、beta、nightly、preview 版本放进独立验证 lane，禁止自动替换生产默认。预发布版本可以用来观察方向和做灰度测试，但不能替代稳定版验收。

用户操作链路:

1. 记录版本、发布时间、来源链接、是否 prerelease 和 release body 完整度。
2. 固定验证任务，不用生产仓库首跑。
3. 标注 owner、可写目录、网络边界、凭证边界和回滚命令。
4. 跑最小真实任务并保存本地证据。
5. 只有稳定版或明确批准后才推广默认值。

风险: alpha 更新速度快，昨天可用的行为今天可能已变化。

### 知识卡片: Proxy Credential Boundary

当 agent CLI 支持企业代理、mTLS 或客户端证书时，把网络路由和凭证授权当成独立风险面，而不是普通联网能力。

用户操作链路:

1. 标明代理地址、证书来源、适用域和有效期。
2. 日志默认脱敏，不把证书路径、指纹或账号细节写入公开报告。
3. 区分模型请求、网页请求、包管理请求和 Git 请求。
4. 每次失败记录 HTTP 状态和证书错误类型，不直接重试到更宽权限。
5. 保留撤销、轮换和本地只读检查路径。

风险: 代理打通后，agent 的外联面会比原计划更宽。

### 知识卡片: Sandbox Grant Receipt

每次给 agent 授权路径、工具或开发环境，都留一张“授权小票”，写清来源、范围、原因和撤销条件。

用户操作链路:

1. 记录 grant source、path/tool、read/write、reason、owner、time。
2. 把自动检测到的 developer tools 与手动授予的权限分开。
3. 输出进入公开站点前做 local-path/secret scan。
4. 恢复会话后重新读权限，不沿用旧分类。
5. 任务完成后撤销临时授权或记录保留理由。

风险: 只看最终能访问什么，会漏掉权限是如何来的。

### 知识卡片: Replay-Safe Guardrail Contract

被 guardrail 拦截的工具输出不能再通过 replay、checkpoint、session store 或应用自有副本回到模型上下文。

用户操作链路:

1. 标注哪些输出可持久化、哪些只能本地短期审计。
2. guardrail trip 后替换或 withheld 模型可见内容。
3. 外部副作用单独记录，不因 replay 清理而假装已撤销。
4. 对 live RunState、serialized checkpoint 和 new run 三种路径分别测试。
5. 应用自有日志也做同等脱敏策略。

风险: SDK 清理 replay state 不会自动清理外部系统和应用自有存储。
